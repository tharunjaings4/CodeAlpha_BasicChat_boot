# CodeAlpha Basic Chatbot

## About
A beginner-friendly chatbot developed using Python as part of my CodeAlpha Python Internship.

## Features
- Accepts text input from the user
- Responds to recognized messages
- Handles empty input
- Uses conditional statements to select responses

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download `chatbot.py`.
3. Open a terminal in the project folder.
4. Run:

   `python chatbot.py`
