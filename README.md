# CodeAlpha Basic Chatbot

## About
A beginner-friendly chatbot developed using Python as part of my CodeAlpha Python Programming Internship.

## Features
- Accepts text input from the user.
- Responds to recognized messages.
- Handles empty input.
- Uses conditional statements to select appropriate responses.
- Allows users to exit the conversation.

## Technologies Used
- Python 3
- Python built-in functions and conditional statements

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python chat_boot.py`

## Project Structure
- `chat_boot.py` — Contains the chatbot program.
- `README.md` — Contains project information and instructions.
